Course materials for MEAI 502 (CS 4082): lectures, labs, assignments and

---

## Getting started

Everything runs in **Google Colab** — nothing to install.

1. Open [colab.research.google.com](https://colab.research.google.com) and sign in.
2. `File → Upload notebook`, or open a notebook straight from this repo with
   `File → Open notebook → GitHub` and paste this repository's URL.

Prefer to work locally? You will need Python 3.10+ with `numpy`, `pandas`,
`matplotlib`, `seaborn` and `scikit-learn`.
