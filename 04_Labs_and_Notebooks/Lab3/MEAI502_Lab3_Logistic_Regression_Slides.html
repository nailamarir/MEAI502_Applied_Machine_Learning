Sigmoid and Prediction

From a score to a probability to a class

Activity 2 · Sigmoid

The sigmoid in code

\[g(z)=\frac{1}{1+e^{-z}}\]

In NumPy, \(e^{-z}\) is np.exp(-z). So the formula becomes one line:

1 / (1 + np.exp(-z))

np.exp works on a whole array: one number in, one out; 455 in, 455 out.

Activity 2 · Prediction

From probability to class: the 0.5 rule

Predict 1 if probability \(\ge\) 0.5, otherwise 0.

p = np.array([0.15, 0.40, 0.50, 0.73, 0.95]) p >= 0.5 # [False, False, True, True, True] (p >= 0.5).astype(int) # [0, 0, 1, 1, 1]

Step 1 · compare

>= compares every number at once and gives True / False.

Step 2 · convert

.astype(int) turns True into 1 and False into 0.

0.50 counts as class 1 (≥, not >)

Activity 3 · Decision boundary

All scores in one line: Xb @ theta

\(\begin{bmatrix}1&1&1\\1&2&3\end{bmatrix}\begin{bmatrix}-3\\1\\1\end{bmatrix}=\begin{bmatrix}-3+1+1\\-3+2+3\end{bmatrix}=\begin{bmatrix}\textcolor{#1d4ed8}{-1}\\\textcolor{#dc2626}{2}\end{bmatrix}\)

Each row times θ gives that patient's \(z\). @ does every row at once.

Boundary: \(z=0\) ⟺ \(x_1+x_2=3\). Same idea for 455 tumours: Xb is 455 × 3, z has 455 numbers.

Cost and Gradient Descent

Measure the error, then learn θ yourself

Activity 4 · Cost

The cost function, safely

def cost(Xb, y, theta): p = sigmoid(Xb @ theta) p = np.clip(p, 1e-15, 1 - 1e-15) # never 0 or 1 return -np.mean(y*np.log(p) + (1-y)*np.log(1-p))

np.mean = \(\frac1m\sum\). Start check: with θ = 0 every p = 0.5, so \(J=\log 2=\) 0.693.

Why np.clip?

If p = 0 exactly, \(\log 0=-\infty\) and the loss becomes inf / nan. Clipping keeps it finite.

Activity 4 · Gradient descent

One gradient descent step, in code

\[\text{gradient}=\frac1m X^T(p-y),\qquad \theta:=\theta-\alpha\cdot\text{gradient}\]
p = sigmoid(Xb @ theta) # 1 predict gradient = Xb.T @ (p - y) / m # 2 direction theta = theta - alpha * gradient # 3 step

p − y = how wrong each prediction is.

Shapes: Xb.T (3 × 455) @ (455) → 3 numbers, one per θ.

Minus: the gradient points uphill; we step downhill.

Repeat these 3 lines many times (iterations) and θ improves each time.

Activity 5 · Pipeline

Pipelines prevent data leakage

✗ Wrong: scale everything first

X_s = StandardScaler().fit_transform(X) X_train, X_test = train_test_split(X_s, …)

μ and σ were computed with the test tumours: test information leaks into training.

✓ Right: a pipeline

model = make_pipeline( StandardScaler(), LogisticRegression(max_iter=1000)) model.fit(X_train, y_train)

fit learns μ, σ and θ from training data only; predict reuses them on new data.

One object, two steps, applied in the same order every time: scale → classify.
