MEAI502 Lecture 01: Introduction to Machine Learning
=====================================================

SCORM 1.2 package for Blackboard and other SCORM-compatible LMS platforms.
The launcher also supports SCORM 2004 APIs when provided by the LMS.

UPLOAD
  Upload MEAI502_Lecture01_Introduction_to_ML_SCORM.zip as a SCORM content package.

TRACKING
  lesson_status   : incomplete -> completed when slide 50 is reached
  lesson_location : highest slide reached for resume support
  session_time    : time spent in the lesson

FILES
  imsmanifest.xml   SCORM manifest; keep this name at the package root
  index.html        launcher and LMS communication host
  content.html      self-contained lecture deck
  scorm.js          LMS communication and progress tracking

The lecture's Google Fonts request is optional; it falls back to local fonts when blocked.
