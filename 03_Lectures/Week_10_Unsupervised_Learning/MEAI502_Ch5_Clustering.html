Part 1 · Unsupervised learning

Supervised vs unsupervised learning

Supervised

\(\{(x^{(1)},y^{(1)}),(x^{(2)},y^{(2)}),\dots,(x^{(m)},y^{(m)})\}\)

Labels are given. Goal: fit a hypothesis, such as a decision boundary.

Unsupervised

\(\{x^{(1)},x^{(2)},x^{(3)},\dots,x^{(m)}\}\)

No labels \(y\). Goal: ask the algorithm to find some structure in the data.

Part 1 · Clustering

Clustering: one kind of structure

Given unlabeled points, an algorithm might discover that they form separate groups.

Clustering algorithm

Automatically groups the data into coherent subsets, called clusters.

Clustering is our first unsupervised learning algorithm. Other unsupervised methods find other kinds of structure.
Part 1 · Why clustering?

Applications of clustering

🛍️ Market segmentation

Group a customer database into market segments, to sell to and serve each segment better.

👥 Social network analysis

Find coherent groups of friends, for example from who emails whom most often.

🖥️ Organize computing clusters

Find which machines in a data center work together, to lay out resources and the network better.

🌌 Astronomical data analysis

Group astronomical observations to help understand how galaxies form.

Part 2 · Formally

The K-means algorithm

Input

  • \(K\): the number of clusters
  • Training set \(\{x^{(1)},\dots,x^{(m)}\}\)
  • \(x^{(i)}\in\mathbb{R}^n\) (no \(x_0=1\) convention)
K (capital) = number of clusters.
k (lowercase) = index of one cluster, from 1 to K.

Randomly initialize \(K\) cluster centroids \(\mu_1,\mu_2,\dots,\mu_K\in\mathbb{R}^n\)

Repeat {

for \(i=1\) to \(m\):

\(c^{(i)}:=\) index (1 to K) of the centroid closest to \(x^{(i)}\)

\(c^{(i)}=\arg\min_k \lVert x^{(i)}-\mu_k\rVert^2\)

cluster assignment step

for \(k=1\) to \(K\):

\(\mu_k:=\) average (mean) of the points assigned to cluster \(k\)

move centroid step

}

Part 2 · Move centroid step

A worked example

Suppose examples 1, 5, 6 and 10 were assigned to cluster 2:

\[c^{(1)}=c^{(5)}=c^{(6)}=c^{(10)}=2\]

Then the move centroid step sets:

\[\mu_2=\tfrac{1}{4}\big[x^{(1)}+x^{(5)}+x^{(6)}+x^{(10)}\big]\in\mathbb{R}^n\]

With numbers: \(x^{(1)}=(1,2),\ x^{(5)}=(2,1),\ x^{(6)}=(3,3),\ x^{(10)}=(2,2)\)

\(\mu_2=\tfrac14(8,\,8)=\mathbf{(2,\,2)}\)

What if a cluster gets no points?

  • Most common: eliminate that centroid, leaving \(K-1\) clusters.
  • If you really need \(K\) clusters: randomly re-initialize that centroid.

In practice this does not happen often.

Part 2 · Non-separated clusters

K-means also works without clear groups

A T-shirt maker measures the height and weight of customers. The data has no separate groups.

With K = 3, K-means still splits customers into segments S, M, L, and we design one size per segment: market segmentation.

Part 3

Optimization
Objective

What K-means is minimizing

Part 3 · Notation

One new piece of notation

Reminder: \(c^{(i)}\) = index of the cluster \(x^{(i)}\) is assigned to; \(\mu_k\) = location of centroid \(k\).

\(\mu_{c^{(i)}}\)

the centroid of the cluster to which \(x^{(i)}\) has been assigned

Example: \(x^{(i)}\) is assigned to cluster 5 \(\Rightarrow\ c^{(i)}=5\ \Rightarrow\ \mu_{c^{(i)}}=\mu_5\)
Part 3 · Cost function

The distortion cost function

\[J\big(c^{(1)},\dots,c^{(m)},\mu_1,\dots,\mu_K\big)=\frac{1}{m}\sum_{i=1}^{m}{\color{#dc2626}\big\lVert x^{(i)}-\mu_{c^{(i)}}\big\rVert^2}\qquad \min_{c,\ \mu}\ J\]

The average squared distance between each example and the centroid of the cluster it is assigned to. Also called the distortion.

Part 3 · Why the two steps work

Each step minimizes J

Cluster assignment step

Minimizes \(J\) with respect to \(c^{(1)},\dots,c^{(m)}\), holding \(\mu_1,\dots,\mu_K\) fixed.

Move centroid step

Minimizes \(J\) with respect to \(\mu_1,\dots,\mu_K\), holding the \(c^{(i)}\) fixed.

Debugging: J must never increase from one step to the next. If it does, there is a bug in your code.

Part 4

Random
Initialization

How to start, and how to avoid local optima

Part 4 · The recommended way

Initialize on random training examples

  1. Make sure \(K \lt m\) (fewer clusters than examples).
  2. Randomly pick \(K\) training examples.
  3. Set \(\mu_1,\dots,\mu_K\) equal to these \(K\) examples.
\(\mu_1=x^{(i)},\ \ \mu_2=x^{(j)},\ \dots\) for random \(i\neq j\)

lucky pick

unlucky pick

Part 4 · Try it

K-means can get stuck in local optima

K = 3. Each click picks 3 random examples as starting centroids, then runs K-means to convergence.

Part 4 · The fix

Multiple random initializations

For \(i=1\) to \(100\) {

Randomly initialize K-means

Run K-means → get \(c^{(1)},\dots,c^{(m)},\mu_1,\dots,\mu_K\)

Compute the cost function (distortion) \(J\)

}

Pick the clustering with the lowest \(J\).

Typical number of runs: 50 to 1000.

Helps most when \(K\) is small (2 to about 10). For large \(K\) (hundreds), the first run is usually already decent.

Part 5

Choosing the
Number of Clusters

How to pick K

Part 5 · The problem

How many clusters do you see?

Some people see 2 clusters, some 3, some 4. The true number is genuinely ambiguous.

With no labels, there is often no single right answer. In practice, K is still most often chosen by hand, by looking at the data and the results.
Part 5 · The elbow method

The elbow method

Run K-means for K = 1, 2, 3, …, compute the distortion J for each, and plot J against K.

Clear elbow at K = 3: J drops fast, then slowly

No clear elbow: 3? 4? 5?

Worth a try, but don't expect it to work for every problem: an ambiguous curve is just as common.
Part 5 · A better way

Choose K for the later purpose

We usually run K-means for a downstream purpose. Ask: which K serves that purpose best?

K = 3: S, M, L

K = 5: XS, S, M, L, XL

More sizes: T-shirts fit customers better.
Fewer sizes: cheaper to make and sell.
In Python

K-means in NumPy

def find_closest_centroids(X, mu): d = ((X[:, None, :] - mu[None, :, :]) ** 2).sum(axis=2) return d.argmin(axis=1) # c(i) for every example def compute_centroids(X, c, K): return np.array([X[c == k].mean(axis=0) for k in range(K)]) def kmeans(X, K, iters=10): mu = X[np.random.choice(len(X), K, replace=False)] # random init for _ in range(iters): c = find_closest_centroids(X, mu) # assignment step mu = compute_centroids(X, c, K) # move centroid step J = ((X - mu[c]) ** 2).sum(axis=1).mean() # distortion return c, mu, J

Indexing

Wrap-up

Key takeaways

1. Unsupervised learning: data \(x^{(i)}\) with no labels; find structure such as clusters.

2. K-means repeats: assign each point to the closest centroid, then move each centroid to the mean of its points.

3. It minimizes the distortion \(J=\frac1m\sum\lVert x^{(i)}-\mu_{c^{(i)}}\rVert^2\); J never increases.

4. Initialize centroids on \(K\) random examples. Run many times and keep the lowest J.

5. Choose K by hand, with the elbow method if it shows a clear elbow, or better, by what serves the downstream purpose.
